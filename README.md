### RoboNav Firmware Workshop

This workshop repository is divided into 5 steps.

Each step's folder has a Client_[step].py and Server_[step].cpp file for you to complete. 
Each step also has answer keys, which you should feel free to reference at any point. It's recommended that you look through them if you're interested in extra notes and explanations. 

By default, the next step's scaffolding code uses the previous step's answer key. You should replace it with your own implementation from the previous step. **However**, keep the new step's instructions (CTRL+F "TODO"), corresponding hints, and any new example code (it will be clearly identified).
